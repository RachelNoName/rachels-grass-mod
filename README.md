# Rachels Grass Mod
Ads a few grass related blocks and items. Inspired by the grass cutting mechanic from [GregTech 6](https://gregtech.overminddl1.com/).

# Features
(Note: The mod is still HEAVILY in development so almost none of these are added yet. This list is currently more like a list of planned features. I am working on it!)   

- ![Grass](src/main/resources/assets/rachels_grass/textures/item/grass_bundle.png) Adds new unique grass related blocks and items.  
- ![Grass](src/main/resources/assets/rachels_grass/textures/item/dry_grass_bundle.png) Cut grass using swords (can be configured) to obtain grass bundles to craft grass blocks.
- ![Grass](src/main/resources/assets/rachels_grass/textures/item/dry_grass_bundle.png) The grass block can dry if placed in the sun or become wet again if placed in rain.
- ![Grass](src/main/resources/assets/rachels_grass/textures/item/dry_grass_bundle.png) Grass can also become wet by using a water bottle or dried by smelting in a furnace. 
- ![Grass](src/main/resources/assets/rachels_grass/textures/item/dry_grass_bundle.png) Normal grass can be composted and dry grass can be used as furnace fuel and to make campfires and torches.  
- ![Grass](src/main/resources/assets/rachels_grass/textures/item/dry_grass_bundle.png) Grass can be painted to prevent it from drying or becoming wet (usefull for building purposes).
- ![Grass](src/main/resources/assets/rachels_grass/textures/item/dry_grass_bundle.png) Ads a firestarter, a primitive flint and steel made from a dry grass bundle and sticks.
